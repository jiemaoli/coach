# Pine Scripts

TradingView Pine helpers for studying the author's core price-action setups.

These scripts are learning aids, not automated trading systems. Use them to mark candidate structures, then review the chart manually.

## Recommended Study Order

1. `a2-setup-pro.pine` with `a2-setup-guide.md`
2. `w1p-setup-pro.pine` with `w1p-setup-guide.md`
3. `dp-setup-pro.pine` with `dp-setup-guide.md`
4. `fbo-setup-pro.pine` with `fbo-setup-guide.md`

This follows the project source emphasis: start with A2, then W1P, then move into breakout/failure structures such as DP and fBO.

## Files

All scripts include the 20 EMA plot and optional session bar count labels, so TradingView free-plan users can replace separate EMA and bar-count indicators with one setup helper.

`a2-setup-pro.pine`: A2 continuation setup helper.

`w1p-setup-pro.pine`: Wedge first pullback helper.

`dp-setup-pro.pine`: Double top/bottom pullback helper.

`fbo-setup-pro.pine`: Failed breakout helper.

Each guide explains labels, parameters, suggested presets, and a study checklist.
